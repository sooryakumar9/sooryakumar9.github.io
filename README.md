# Portfolio

Personal site for Soorya Kumar, full stack software developer in Bengaluru.

**Live at [sooryakumar9.github.io](https://sooryakumar9.github.io)**

Next.js static export with TypeScript, Tailwind CSS and GSAP. The artwork is drawn at runtime on
canvas rather than shipped as images, and the hero is a WebGL fragment shader. Deployed to GitHub
Pages by `.github/workflows/deploy.yml`.

```bash
npm install
npm run dev     # localhost:6300
npm run build   # static export into out/
npm run lint
```

Notes on the parts that are easy to break are in [AGENTS.md](AGENTS.md).
