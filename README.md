# Portfolio

My personal site. Live here: **https://sooryakumar9.github.io**

It reads like one long engineering document. You scroll through it and each
project shows up as a small interactive diagram you can actually play with,
not just a screenshot.

## Tech

Next.js, TypeScript, Tailwind CSS and Motion. It builds to static HTML and
ships to GitHub Pages automatically on every push to main.

## Run it locally

```bash
npm install
npm run dev
```

All the writing and project data lives in `src/content`. The interactive
pieces live in `src/components`. Start there if you want to poke around.
