# Portfolio

My personal site. Live at **[sooryakumar9.github.io](https://sooryakumar9.github.io)**.

I'm Soorya Kumar, a full stack software developer in Bengaluru. I built this as a Next.js static
export with TypeScript, Tailwind CSS and GSAP. The artwork is drawn at runtime on canvas rather
than shipped as images, and the hero is a WebGL fragment shader. It deploys to GitHub Pages from
the workflow in `.github/workflows`.

Notes on the parts that are easy to break are in [AGENTS.md](AGENTS.md).
